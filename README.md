Backend setup:
- FastAPI server on port 8000
- MySQL database (XAMPP)

To run the backend:
```bash
cd backend
pip install -r requirements.txt
python main.py
```

Frontend setup:
- Next.js on port 3000

To run the frontend:
```bash
cd frontend
npm install
npm run dev
```

Or to run both:
```bash
pnpm dev
```
